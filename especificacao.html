UC01: Procurar estabelecimento

Ator Principal Usuário
Pré-condições Ter informado suas preferências
Pós-condições Mostra restaurantes compatíveis às preferências pessoais ao usuário

Fluxo Principal de Ações:

  1. O usuário acessa a funcionalidade de buscar estabelecimento.
  2. O sistema apresenta o formulário solicitando o tipo de comida desejada.
  3. O usuário preenche os campos e informa suas preferências à I.A.
  4. O sistema valida os dados e envia para processamento.
  5. O sistema lista os restaurantes compatíveis com o perfil.

Fluxo Alternativo:

  1. [Passo 3a] O usuário deixa o campo de preferências vazio e clica em buscar.
  2. O sistema exibe automaticamente os restaurantes mais populares e bem avaliados da região atual.

Exceções:

  1. [Passo 4a] O serviço de I.A ou banco de dados encontra-se offline.
  2. O sistema interrompe a busca e exibe a mensagem de erro "Serviço indisponível no momento, tente novamente mais tarde".

UC02: Login/Autenticação

Ator Principal Usuário
Pré-condições Possuir cadastro prévio no sistema
Pós-condições Usuário logado e com acesso às funcionalidades restritas

Fluxo Principal de Ações:

  1. O usuário acessa a página de login.
  2. O usuário insere seu e-mail e senha.
  3. O usuário clica no botão "Entrar".
  4. O sistema valida as credenciais informadas.
  5. O sistema redireciona o usuário para a página inicial logada.

Fluxo Alternativo:

  1. [Passo 2a] O usuário esqueceu sua senha e clica em "Esqueci minha senha".
  2. O sistema redireciona o usuário para o fluxo de redefinição de credenciais.

Exceções:

  1. [Passo 4a] O sistema verifica que a senha informada está incorreta.
  2. O sistema exibe a mensagem "E-mail ou senha incorretos" e solicita nova tentativa.
